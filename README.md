# «Оглавление телеграм-канала» — готовый каталог постов

**Готовый набор файлов**: канал получает ОГЛАВЛЕНИЕ всех постов — мини-приложение
с темами, поиском и датами, которое открывается прямо в Telegram по кнопке.
Хостинг бесплатный навсегда (GitHub Pages), публикация новостей автоматическая
(GitHub Actions). Ни одного сервера арендовать не нужно.

- Цена комплекта: **4 900 ₽** (разово, без подписки)
- Стоимость владения: **0 ₽/мес**
- Время настройки по гайду: **30–60 минут**

---

## Как это устроено

```
                    ВЛАДЕЛЕЦ КАНАЛА (один раз, ~40 минут)
     ┌──────────────────────────────────────────────────────────┐
     │  1. Репозиторий GitHub + файлы набора (drag & drop)      │
     │  2. Бот через BotFather (токен → в секреты GitHub)       │
     │  3. Канал → бот назначен админом (публикация постов)     │
     │  4. GitHub Pages включён (папка /docs)                   │
     │  5. config.js заполнен (канал + лицензионный ключ)       │
     └──────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┴────────────────────┐
        ▼                                          ▼
  НОВОСТНОЙ КОНВЕЙЕР                        МИНИ-АПП «ОГЛАВЛЕНИЕ»
  (GitHub Actions, 4 раза/сутки)            (GitHub Pages, бесплатно)
  RSS-источники → анонс в канал             темы · поиск · месяцы · алфавит
  → posts.json обновлён → Pages             · типы постов — на каждый пост
  переопубликован автоматически             кнопка «Оглавление» закреплена
                                            в шапке канала
```

Читатель открывает кнопку «Оглавление» в канале и видит каталог всех постов.
Владелец ничего больше не делает — всё работает само.

## Состав набора

| Путь | Что это | Кому трогать |
|---|---|---|
| `docs/index.html` | Мини-апп «Оглавление» (одна страница, без зависимостей) | никому — работает как есть |
| `docs/config.js` | **Конфиг**: название канала, ссылка, цвет, лицензия | покупателю (2 строки) |
| `docs/posts.json` | Данные оглавления (заполняется автоматически) | никому — автоматика |
| `docs/topics.json` | **Темы оглавления** (карточки-разделы) | покупателю по желанию |
| `.github/workflows/news.yml` | Новостной конвейер: RSS → канал → оглавление | никому |
| `.github/workflows/import.yml` | Импорт истории канала из экспорта Telegram | никому |
| `.github/workflows/button.yml` | Публикация и закрепление кнопки «Оглавление» | никому |
| `pipeline/news_pipeline.py` | Скрипт новостного конвейера | никому |
| `pipeline/export_to_posts.py` | Конвертер экспорта → оглавление | никому |
| `pipeline/ai_tags.py` | Подготовка постов для разметки тегами любым ИИ | покупателю по желанию |
| `pipeline/suggest_topics.py` | Черновик тем из тегов постов | покупателю по желанию |
| `pipeline/toc_button.py` | Скрипт кнопки оглавления | никому |
| `pipeline/sources.json` | **Список RSS-источников новостей** | покупателю по желанию |

## Как собирается оглавление (4 уровня, от простого к умному)

1. **Всегда и без усилий — универсальные разделы.** Уже после первого импорта
   оглавление показывает карточки «📅 По месяцам», «🔤 По алфавиту» и
   «🎭 По типу постов» (тексты, фото, видео, аудио, опросы, файлы — типы
   определяются автоматически). Новости удобно листать по месяцам, блог —
   по алфавиту заголовков.
2. **Если в постах есть хэштеги — появятся ТЕМЫ.** Импорт собирает теги сам,
   а `pipeline/suggest_topics.py` превратит самые частые в карточки тем
   (бренд-теги отсекаются автоматически).
3. **Тегов нет, но хочется тем — ИИ за пределами продукта.**
   `pipeline/ai_tags.py --prepare` соберёт посты в готовый промпт: скопируйте
   его в любой чат-бот (ChatGPT/Claude/GigaChat), сохраните ответ и выполните
   `--apply` — теги расставлены, темы готовы. Продукт не платит за ИИ —
   владелец пользуется своим.
4. **Поиск и лента** работают всегда, поверх любых группировок.

## Два сценария использования

1. **Контентный канал (уже есть посты).** Экспортируете канал через
   Telegram Desktop (`result.json`), кладёте файл в папку `import/`, запускаете
   действие «Импорт истории» — оглавление наполнено всем архивом. Новостной
   конвейер при этом можно не включать.
2. **Новостной канал (автопубликация).** Заполняете `sources.json`, и конвейер
   4 раза в сутки сам публикует анонсы в канал и обновляет оглавление.
   Так устроен демо-канал «Добрые вести» — витрина продукта.

Оба сценария можно совмещать: архив из экспорта + свежие новости из RSS.

## Быстрый старт (для нетерпеливых)

Кратко:

1. Загрузите все файлы набора в свой новый репозиторий GitHub.
2. BotFather → `/newbot` → токен бота.
3. Канал → добавить бота админом (право «Публикация сообщений»).
4. Секреты репозитория: `BOT_TOKEN`, `CHANNEL_USERNAME`.
5. Settings → Pages → Branch `main`, папка `/docs`.
6. В `docs/config.js` впишите канал и лицензионный ключ.
7. Actions → «Кнопка оглавления» → Run → пост с кнопкой закреплён в канале.

## Требования

- Аккаунт GitHub (бесплатный) и аккаунт Telegram.
- Канал должен иметь публичный @юзернейм (для ссылок на посты).
- Всё. Серверы, базы данных и оплата хостинга не нужны.
